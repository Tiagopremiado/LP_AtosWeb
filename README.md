# ATOSweb — Landing Page

Landing page oficial de alta conversão da **ATOSweb**.

> "Não é só sobre entregar uma página. É sobre fazer ela funcionar para alguém."

## 🚀 Tecnologias

- **HTML5 Semântico**
- **Tailwind CSS** (via CDN com design tokens personalizados)
- **GSAP & ScrollTrigger**
- **Vanilla JavaScript** (Accordion fluido 60fps, Modal de Orçamento com WhatsApp dinâmico)
- **Design Editorial & Futurista**

## 📂 Estrutura do Projeto

- `index.html` — Estrutura completa (Hero, Benefícios, Sobre, Serviços, Portfólio, Como Funciona, Prova Real, FAQ, CTA Final, Footer e Modal).
- `assets/` — Imagens de alta fidelidade e backgrounds do projeto.
- `.gitignore` — Arquivos e caches ignorados no versionamento.

## 🛠️ Como Executar Localmente

Você pode abrir o arquivo `index.html` diretamente no seu navegador ou iniciar um servidor local rápido:

```bash
# Python
python -m http.server 3000
```

Acesse em: `http://localhost:3000`

## 🌐 Deploy na Vercel

1. Importe este repositório no painel da **Vercel**.
2. Framework Preset: **Other** (Site Estático).
3. Clique em **Deploy**.
